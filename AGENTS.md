# AGENTS.md — Проектный регламент для AI-агентов команды MedAI

Данный документ — единый обязательный регламент для любых AI-ассистентов (Cursor, Claude, Gemini, Copilot и др.), работающих в репозитории проекта MedAI по методологии **Spec-Driven Development (SDD)**.

---

## 1. Рабочий цикл агента (SDD Cycle)

Разработка любой функциональности ведётся строго через локальный skill `.agents/skills/sdd/SKILL.md`:

```text
specify -> plan -> implement -> verify
```

1. **specify:** Сформулируй требования в `specs/changes/<change-id>/spec.md` с идентификаторами `REQ-xxx` и BDD-сценариями. Зарегистрируй спецификацию в `specs/status.yaml` со статусом `draft` скриптом `spec_status.py`.
2. **plan:** Подготовь пошаговый инженерный план реализации в `specs/changes/<change-id>/plan.md`. Согласуй план с тимлидом (Лука).
3. **implement:** Реализуй задачу проверяемыми инкрементами строго в границах своей зоны ответственности. Проверь код линтером `make lint` и тестами `make test`.
4. **verify:** Зафиксируй доказательства соответствия требованиям в `specs/changes/<change-id>/verification.md` с терминальным выводом тестов. Обнови статус в `done` скриптом `spec_status.py`.
5. **changelog:** Зафиксируй изменение в [CHANGE_HISTORY.md](CHANGE_HISTORY.md) и актуализируй архитектурный каталог [docs/](docs/).

## 3. Инженерные инварианты и безопасность

1. **Неприкосновенность утвержденного UI:** Дизайн и макеты Каты в каталоге `ui/` запрещено самовольно переделывать, менять концепцию или заменять сторонними шаблонами. Любые доработки согласовываются с автором и ведутся в отдельной ветке.
2. **Строго относительные пути:** Категорически запрещено использовать абсолютные пути конкретной машины (`/Users/...`, `C:\...`). Все ссылки обязаны быть строго относительными от корня проекта (`docs/...`, `specs/...`, `ui/...`).
3. **Единый фасад команд:** Все операции сборки, запуска, тестирования и аудита спецификаций выполняются через [Makefile](Makefile).
4. **Управление реестром через CLI:** Запрещено редактировать `specs/status.yaml` вручную; разрешено только через `.agents/skills/sdd/scripts/spec_status.py`.
5. **Безопасность окружения:** Запрещены деструктивные команды (`rm -rf`, сбросы git) и любые операции за пределами директории проекта (`./`).
6. **Строгий инженерный стиль (Zero Water):** Архитектура и Data Flow — схемы Mermaid, математический аппарат — формулы LaTeX, контракты — типизированный JSON. Декоративные эмодзи в технической документации запрещены.
