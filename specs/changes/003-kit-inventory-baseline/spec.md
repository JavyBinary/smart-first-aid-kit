# 003-kit-inventory-baseline: Базовый инвентарь домашней аптечки

## Цель
Реализовать интерфейс управления домашней аптечкой в боковой выдвижной панели `ui/site.html`: просмотр списка, добавление медикаментов с формой и дозировкой, удаление и фильтрация по тегам.

## Требования
- REQ-001: Выдвижная панель аптечки с анимацией открытия/закрытия по кнопке на боковом рейле.
- REQ-002: Модальное окно добавления препарата с полями: наименование, форма выпуска, дозировка, симптоматические теги.
- REQ-003: Фильтрация списка препаратов по тегам с логикой «И» (отображаются только препараты, содержащие все выбранные теги).
- REQ-004: Удаление препарата из аптечки с модальным подтверждением.
- REQ-005: Изоляция хранения аптечки в ключе `medai_kit` в `localStorage`.

## Критерии приемки
- [x] Панель аптечки открывается, медикаменты отображаются карточками.
- [x] Добавление нового препарата сохраняет его в `medai_kit`.
- [x] Логика фильтрации «И» проверена на пересечении тегов («боль» + «жар»).
