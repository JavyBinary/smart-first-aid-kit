# 009-ui-frontend-scaffold: Модульная архитектура клиентского приложения (Vite + Vanilla JS)

## Цель
Перевести клиентский интерфейс из разрозненных HTML-файлов в современную модульную архитектуру (каталог `frontend/`) на базе чистых ES-модулей и сборщика Vite со строгим разделением на компоненты (`src/components/`), изолированный сетевой слой (`src/api/`), реактивный Store (`src/state/`) и дизайн-токены Сбер Еаптеки (`src/styles/`).

## Требования
- REQ-001: Создать изолированный каталог `frontend/` с `package.json`, `vite.config.js` и структурой `src/`.
- REQ-002: Разработать систему дизайн-токенов в светлой теме (`tokens.css`): акцентный изумрудный `#00B074`, глубокий хвойный `#0A3B32`, пастельные медицинские фоны и мягкие тени.
- REQ-003: Реализовать базовый HTTP-клиент `client.js` и API-модули `auth.api.js`, `kit.api.js`, `chat.api.js` с архитектурой Seamless Fallback.
- REQ-004: Реализовать реактивный централизованный Store (`store.js`) на базе паттерна Publish/Subscribe.
- REQ-005: Обеспечить запуск как через `make run-ui` (встроенный сервер), так и через `make dev-frontend` (Vite).

## Критерии приемки
- [x] Каталог `frontend/` инициализирован, структура модулей создана.
- [x] Дизайн-токены определены и подключены.
- [x] Реактивный Store обновляет подписчиков при изменении состояния.
