# 006-emergency-red-flags: Протокол неотложной помощи Red Flags

## Цель
Реализовать механизм немедленного распознавания угрожающих жизни симптомов (`ожог`, `кровотечение`, `потеря сознания`) с блокировкой выдачи таблеток и выводом протокола первой доврачебной помощи и номера 112.

## Требования
- REQ-001: Реализовать клиентский классификатор экстренных ключевых слов.
- REQ-002: При срабатывании выводить ярко-красный блок `.emergency-card` с предупреждением и номером вызова экстренных служб (112).
- REQ-003: Заблокировать выдачу фармакологических рекомендаций при активации Red Flag.
- REQ-004: Выводить пошаговый утвержденный алгоритм первой помощи (охлаждение водой, стерильная повязка).

## Критерии приемки
- [x] При вводе запроса со словом «ожог» диалог выводит баннер `.emergency-card`.
- [x] Телефон 112 отображается крупным шрифтом с возможностью быстрого набора.
