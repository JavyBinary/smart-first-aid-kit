# 011-ui-medicine-catalog: Витрина лекарств в стиле Яндекс Лавки и Еды

## Цель
Реализовать интерактивную витрину популярных медикаментов с горизонтальной каруселью категорий, живым поиском и механикой быстрого добавления в аптечку по кнопке `+` с дуговой анимацией «полета».

## Требования
- REQ-001: Создать базу каталога из 16+ популярных коммерческих препаратов с дозировками, формами, статусами (OTC / RX) и категориями.
- REQ-002: Реализовать карусель категорий с быстрым переключением (Обезболивающие, ЖКТ, Простуда, Спазмолитики, Аллергия).
- REQ-003: Реализовать строку живого поиска с мгновенной фильтрацией сетки карточек.
- REQ-004: Карточка товара `MedicineCard` с индикацией статуса «Без рецепта» / «По рецепту» и дозировки.
- REQ-005: Реализовать анимацию взлета и параболического полета частицы от кнопки `+` в правую колонку аптечки с отскоком иконки.
- REQ-006: Карточка «Свой препарат» для открытия формы добавления редкого лекарства.

## Критерии приемки
- [x] Витрина рендерит карточки, карусель фильтрует по категориям.
- [x] Нажатие на `+` запускает анимацию и добавляет препарат в аптечку.
- [x] Повторный клик заблокирован (статус «✓ В аптечке»).
