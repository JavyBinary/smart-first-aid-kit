# 002-auth-rbac-system: Аутентификация и разграничение ролей (User / Admin)

## Цель
Реализовать интерфейс входа и регистрации пользователей `ui/auth.html` с поддержкой ролевой модели (User и Admin) и автоматической маршрутизацией в соответствующие кабинеты.

## Требования
- REQ-001: Создать экран `ui/auth.html` с переключаемыми табами «Вход» и «Регистрация».
- REQ-002: Валидация формы входа: email по регулярному выражению, пароль не менее 6 знаков, индикация ошибок.
- REQ-003: Маршрутизация ролей: при входе с email `admin@medai.ru` выставляется роль `admin` и выполняется переход на `ui/admin.html`; для всех остальных — роль `user` и переход на `ui/site.html`.
- REQ-004: Сохранение состояния сессии в `localStorage` (`medai_user`, `medai_role`, `medai_name`).

## Критерии приемки
- [x] Экран `ui/auth.html` открывается в браузере, валидация полей работает.
- [x] Ролевая маршрутизация перенаправляет админа на `admin.html`, а пользователя — на `site.html`.
