# 004-admin-corpus-management: Консоль администратора и управление корпусом

## Цель
Реализовать интерфейс администратора `ui/admin.html` для аудита, добавления, редактирования и удаления официальных медицинских инструкций корпуса BM25.

## Требования
- REQ-001: Разработать экран `ui/admin.html` без окна чата, с плашкой статуса («Инструкций в базе: {N} | Поиск BM25: активен»).
- REQ-002: Таблица корпуса с колонками: Название, Категория, Аннотация, Действия.
- REQ-003: Инлайн-редактирование любой ячейки по клику на карандаш с горячими клавишами (`Enter`, `Ctrl+Enter`, `Escape`).
- REQ-004: Модальное окно добавления новой инструкции с валидацией непустых полей и проверкой дубликатов названий.
- REQ-005: Хранение корпуса администратора в ключе `medai_corpus` в `localStorage`.

## Критерии приемки
- [x] Экран `ui/admin.html` отображает актуальный список инструкций.
- [x] Инлайн-редактирование ячеек сохраняет изменения в хранилище.
