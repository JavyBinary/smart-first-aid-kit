# 007-admin-benchmark-inspector: Инспекция метрик BM25 в консоли администратора

## Цель
Реализовать в консоли администратора `ui/admin.html` кнопку и модальное окно инспекции метрик качества поискового ядра BM25 ($MRR$, $Recall@k$, $P_{95}$).

## Требования
- REQ-001: Добавить кнопку «Метрики BM25» в плашку статуса `ui/admin.html`.
- REQ-002: Модальное окно инспекции с отображением: $MRR = 0.842$, $Recall@1 = 77.8\%$, $Recall@3 = 91.1\%$, $Recall@5 = 95.6\%$, задержка $P_{95} = 12\text{ мс}$.
- REQ-003: Отображение параметров алгоритма: $k_1 = 1.5$, $b = 0.75$, лемматизатор `pymorphy3`.
- REQ-004: Сетевой запрос к `GET /api/v1/admin/benchmark/metrics` с локальным fallback при отключенном бэкенде.

## Критерии приемки
- [x] Модальное окно бенчмарка открывается, метрики отображаются.
- [x] Значения соответствуют спецификации качества.
