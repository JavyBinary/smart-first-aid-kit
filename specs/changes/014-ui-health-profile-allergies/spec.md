# 014-ui-health-profile-allergies: Медкарта пользователя (аллергии и хронические болезни)

## Цель
Реализовать модальный модуль персональной медкарты пользователя для учета лекарственных аллергий и хронических заболеваний при RAG-консультации.

## Требования
- REQ-001: Создать компонент `HealthProfileModal.js` с выбором аллергий (пенициллины, НПВП/аспирин, лактоза, сульфаниламиды).
- REQ-002: Поддержать выбор хронических заболеваний (язвенная болезнь ЖКТ, астма, гипертония, сахарный диабет).
- REQ-003: Сохранение медкарты в `localStorage` под ключом `medai_health_profile`.
- REQ-004: Отображение статуса заполненности медкарты в левом рейле пользователя («● Медкарта заполнена»).
- REQ-005: Модальное окно добавления редкого препарата в аптечку (`CustomMedicineModal`).

## Критерии приемки
- [x] Модалка открывается по клику на плашку пользователя внизу левого рейла.
- [x] Выбранные аллергии и хронические заболевания сохраняются.
- [x] Форма добавления редкого препарата сохраняет препарат в аптечку.
