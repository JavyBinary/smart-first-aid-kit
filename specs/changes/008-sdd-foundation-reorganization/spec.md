# 008-sdd-foundation-reorganization: Архитектурная реорганизация репозитория по стандарту SDD

## Цель
Реорганизовать проект MedAI по эталонному стандарту Spec-Driven Development (адаптированному из проекта BMSTU-NIRS), внедрив централизованный реестр `specs/status.yaml`, атомарные изменения `specs/changes/`, архитектурный каталог `docs/` и единый `Makefile`.

## Допущения и контекст
- Реорганизацию проводит тимлид проекта (Лука) в отдельной ветке.
- UI-файлы Каты и прикладные модули RAG/Backend сохраняют свои контракты.

## Требования
- REQ-001: Создать директорию `.agents/skills/sdd/` с CLI-скриптом `spec_status.py` для безопасного управления статусами.
- REQ-002: Развернуть централизованный реестр `specs/status.yaml` со спецификациями 001–008.
- REQ-003: Сформировать каталог живой архитектурной документации `docs/` (README, architecture, bm25, rag, benchmark, api, roles, ui).
- REQ-004: Разработать корневой `Makefile` для стандартизации запуска, тестирования и управления спецификациями.
- REQ-005: Зафиксировать реорганизацию в `AGENTS.md`, `GEMINI.md`, `README.md` и [CHANGE_HISTORY.md](../../CHANGE_HISTORY.md).

## Критерии приемки
- [x] Скрипт `spec_status.py` валидирует и выводит реестр `specs/status.yaml`.
- [x] Команды `make help` и `make spec-list` работают без ошибок.
- [x] Все ссылки в `docs/` и `specs/` строго относительные.
