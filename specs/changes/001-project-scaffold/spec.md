# 001-project-scaffold: Базовая структура репозитория MedAI

## Цель
Инициализировать репозиторий проекта MedAI в рамках дисциплины НИРС (МГТУ им. Н. Э. Баумана), зафиксировать паспорт проекта, состав команды и правила работы AI-ассистентов по методологии Spec-Driven Development.

## Допущения и контекст
- Проект разрабатывается командой из двух человек (Лука, Катя).
- Архитектурный стиль — Spec-Driven Development (SDD).

## Требования
- REQ-001: Создать `README.md` с паспортом проекта, целями, составом команды и базовой картой спецификаций.
- REQ-002: Зафиксировать инженерный регламент `AGENTS.md` и системный промпт `GEMINI.md` с запретом абсолютных путей машины и деструктивных команд.
- REQ-003: Добавить `.gitignore` для исключения системных файлов ОС (`.DS_Store`, `Thumbs.db`) и временных кэшей Python/Node.

## Критерии приемки
- [x] Файлы `README.md`, `AGENTS.md`, `GEMINI.md`, `.gitignore` присутствуют в корне.
- [x] Все ссылки в Markdown стандартизированы как строго относительные.
