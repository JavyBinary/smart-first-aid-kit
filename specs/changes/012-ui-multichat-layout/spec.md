# 012-ui-multichat-layout: Трехколоночный макет и система мультичата

## Цель
Реализовать современный 3-колоночный рабочий интерфейс (левый рейл навигации и мультичата, центральная рабочая зона консультации/витрины, правая колонка аптечки) с поддержкой нескольких сессий диалогов.

## Требования
- REQ-001: Реализовать CSS Grid раскладку: 280px (левый рейл) | 1fr (центр) | 340px (аптечка).
- REQ-002: Мультичат: кнопка «+ Новый диалог» в шапке левого рейла.
- REQ-003: Список сохраненных диалогов с авто-генерацией названия по первому вопросу.
- REQ-004: Переключение между сессиями диалогов с сохранением истории сообщений в `localStorage`.
- REQ-005: Удаление сессий диалогов с защитой от очистки последней активной сессии.
- REQ-006: Верхний таб-бар переключения центральной зоны («Умная консультация» / «Витрина аптеки»).

## Критерии приемки
- [x] Раскладка адаптируется под окно браузера без горизонтального скролла.
- [x] Создание, переключение и удаление диалогов функционируют корректно.
