# 013-ui-mascot-assistant: Векторный интерактивный маскот «Пилюля»

## Цель
Создать векторного интерактивного персонажа-помощника «Пилюля», реагирующего на контекст диалога, ввод запроса, поиск и экстренные медицинские состояния.

## Требования
- REQ-001: Создать SVG-компонент маскота с двухцветной медицинской капсулой (белый/изумрудный) и праздничной шапочкой.
- REQ-002: Реализовать CSS-анимацию парения `floatMascot` и моргания глаз `blinkEyes`.
- REQ-003: Реализовать 4 динамических состояния маскота:
  - `idle`: состояние покоя, покачивание, моргание;
  - `thinking`: состояние поиска BM25, наклон корпуса;
  - `happy`: подпрыгивание при успешном добавлении лекарства в аптечку;
  - `emergency`: тревожное красное свечение при активации протокола Red Flags (112).
- REQ-004: Интегрировать маскота в пустое состояние диалога с речевым облачком и быстрыми чипсами.

## Критерии приемки
- [x] Маскот анимируется в пустом состоянии диалога.
- [x] При отправке вопроса маскот переходит в статус `thinking`.
- [x] При ожоге активируется тревожная подсветка `emergency`.
