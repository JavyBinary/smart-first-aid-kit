# 010-ui-ambient-dynamics: Атмосферная динамика и живой зимний фон

## Цель
Внедрить в интерфейс динамические микроанимации и атмосферный праздничный зимний фон с плавающими частицами, эффектом боке, параллаксом и элементами матового стекла (glassmorphism).

## Требования
- REQ-001: Реализовать компонент `AmbientBackground.js` на HTML5 Canvas с плавающими частицами (снежинки и капсулы).
- REQ-002: Поддержать кинематографичный параллакс частиц при движении курсора мыши.
- REQ-003: Добавить верхнюю праздничную переливающуюся полосу (shimmer animation).
- REQ-004: Стилизовать плавающие панели с эффектом матового стекла (`backdrop-filter: blur(16px)`).
- REQ-005: Реализовать CSS-физику пружинящих нажатий (`cubic-bezier(0.34, 1.56, 0.64, 1)`).

## Критерии приемки
- [x] Canvas плавно рендерит дрейф частиц со скоростью 60 FPS без просадки производительности.
- [x] Параллакс реагирует на курсор мыши.
- [x] Стеклянные панели корректно отображаются поверх живого фона.
