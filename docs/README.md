## 2. Архитектурные инварианты

1. **Строго относительные пути:** Никаких абсолютных путей конкретной машины. Все ссылки валидируются от корня репозитория.
2. **Детерминированность поиска:** Алгоритм BM25 реализуется полностью самостоятельно в чистом Python, без сторонних поисковых библиотек.
3. **Неприкосновенность утвержденного UI:** Дизайн и макеты Каты в каталоге `ui/` неприкосновенны; доработки интерфейса согласовываются в отдельной ветке.
4. **Контейнеризация и независимость:** Клиентский интерфейс поддерживает режим Seamless Fallback (работает как с живым FastAPI, так и автономно).
