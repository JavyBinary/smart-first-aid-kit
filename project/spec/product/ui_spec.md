## 2. Дизайн-система (Design Tokens)

Приложение выполнено в спокойной современной медицинской стилистике с доминантой изумрудного зеленого цвета, ассоциирующегося со здоровьем, чистотой и безопасностью.

| Токен | Значение HEX | Назначение |
|---|---|---|
| `--green` | `#019F74` | Основной акцентный цвет (кнопки, активные элементы, логотип) |
| `--green-dark` | `#017a5a` | Цвет кнопок при наведении (Hover state) |
| `--green-light` | `#e6f7f2` | Фон бейджей наличия, активных фильтров и подсказок |
| `--bg-pattern` | `#f7f9fa` | Фоновый цвет страниц со светлой текстурой пилюль |
| `--card` | `#ffffff` | Фоновый цвет карточек медикаментов и модальных окон |
| `--text` | `#1a1a1a` | Основной цвет заголовков и текста |
| `--text-muted` | `#7a7f85` | Вторичный текст, метаданные, пояснения |

| `--warning` | `#f59e0b` | Уведомления о несовместимости и истекающем сроке |

## 3. Детализация экранов прототипа

### 3.1. Экран авторизации (`ui/auth.html`)
- **Компоненты:**
  - Карточка авторизации по центру экрана с фоновой геометрической текстурой капсул.
  - Таб-переключатель: «Вход» / «Регистрация».
  - Поля формы: Email, Пароль (с кнопкой показать/скрыть), Повтор пароля и Имя (для регистрации).
  - Быстрая подсказка для демонстрации: возможность войти как тестовый пользователь или администратор.
  - Интерактивность: валидация заполненности, сохранение сессии в `localStorage` и переход на целевой интерфейс.

### 3.2. Основной экран пользователя (`ui/app.html`)
Экран разделен на две взаимосвязанные рабочие зоны:
1. **Левая панель (Инвентаризация аптечки):**
   - Верхняя плашка: счетчик медикаментов («12 препаратов в наличии»), поисковая строка по аптечке.
   - Горизонтальная лента категорий/тегов: *Все*, *Обезболивающее*, *От простуды*, *ЖКТ*, *Антисептики*, *Аллергия*, *Успокоительное*.
   - Карточки лекарств: название, форма выпуска (таблетки, спрей, мазь), срок годности (с цветовым индикатором актуальности) и кнопка удаления.
   - Плавающая кнопка «+ Добавить лекарство».
2. **Правая панель (Диалоговое окно MedAI):**
   - Шапка чата с индикатором статуса («Помощник онлайн • Знает вашу аптечку»).
   - Быстрые чипсы-вопросы для мгновенного теста («Болит голова», «Температура 38.5», «Ожог кипятком»).
   - Окно сообщений:
     - Сообщения пользователя (прижаты вправо, нейтральный фон).
     - Сообщения MedAI (прижаты влево, белый фон, структурированные блоки с дозировками, предупреждениями и дисклеймером).
   - Поле ввода запроса с кнопкой отправки и поддержкой нажатия `Enter`.
3. **Модальные окна:**
   - Модальное окно добавления лекарства (название, группа, срок годности, дозировка).
   - Модальное окно профиля пользователя (редактирование имени, смена аватара).
   - Модальное окно подтверждения удаления медикамента.

### 3.3. Панель администратора (`ui/admin.html`)
Экран для демонстрации выполнения роли Администратора:
- **KPI-дашборд поискового движка:**
  - Карточка 1: «Всего документов в корпусе» ($N = 142$).
  - Карточка 2: «Объем уникального словаря» ($|V| = 4\,815$ термов).
  - Карточка 3: «Качество поиска MRR» ($0.84$).
  - Карточка 4: «Recall@3» ($91.2\%$).
- **Таблица медицинских документов:** перечень проиндексированных инструкций (МНН, Торговое наименование, дата обновления, количество термов, действия «Просмотр» / «Удалить»).
- **Форма быстрого добавления инструкции:** возможность вставить текст новой инструкции и симулировать переиндексацию.
- **Интерактивный BM25 тестер:** поле ввода контрольного запроса с отображением результирующего скора BM25 для каждого документа из топ-выдачи.
