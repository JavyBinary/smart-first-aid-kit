# Методология оценки качества поиска (Benchmark Specification)

Спецификация разработана в точном соответствии с разделом 1.5 и разделом 2 («Задание») методических указаний НИРС (`НИРС.pdf`).

---

## 1. Цели бенчмаркинга

Целью бенчмаркинга является объективная количественная оценка качества ранжирования самописного поискового индекса **BM25** на тестовой выборке пользовательских медицинских запросов.

В соответствии с требованиями НИРС:
- Формируется тестовый набор запросов $Q = \{q_i\}_{i \in I}$, равномерно покрывающий все медицинские категории корпуса (НПВП, спазмолитики, антибиотики, антигистаминные, ЖКТ, антисептики, сердечно-сосудистые).
- Для каждого тестового запроса экспертно определяется **не менее трёх релевантных документов** ($|R_{q_i}| \ge 3$).
- Запросы формулируются на естественном языке реальных пользователей (жалобы, симптомы, бытовые вопросы), без прямого копирования фрагментов текста из инструкций.

---

## 2. Математические метрики качества

### 2.1. Mean Reciprocal Rank (MRR)
Метрика оценивает позицию первого найденного релевантного документа в результатах ранжирования:
$$MRR = \frac{1}{|Q|} \sum_{i \in I} \frac{1}{\text{rank}_i}$$
где $\text{rank}_i$ — порядковый номер (позиция, начиная с 1) первого релевантного документа из множества $R_{q_i}$ в отсортированной выдаче по запросу $q_i$. Если ни один релевантный документ не найден в топ-выдаче, принимается $\frac{1}{\text{rank}_i} = 0$.

### 2.2. Полнота поиска на глубине k (Recall@k)
Метрика отражает долю релевантных документов, попавших в первые $k$ позиций ранжированного списка:
$$\text{Recall@k} = \frac{1}{|Q|} \sum_{i \in I} \frac{|Top_k(q_i) \cap R_{q_i}|}{|R_{q_i}|}$$
где $Top_k(q_i)$ — множество первых $k$ документов, возвращенных алгоритмом BM25.

В рамках проекта рассчитываются значения для:
- **Recall@1:** попадание идеального лекарства на первую строчку.
- **Recall@3:** ключевая метрика для RAG (в контекст LLM передается топ-3 документа).
- **Recall@5:** расширенная полнота выдачи.

## 3. Целевые пороговые значения для КТ2

Для успешной защиты алгоритмической части на Контрольной Точке 2 установлены следующие критерии качества:

| Метрика | Минимальный порог | Целевое значение |
|---|:---:|:---:|
| **MRR** | $\ge 0.65$ | **$\ge 0.80$** |
| **Recall@3** | $\ge 0.70$ | **$\ge 0.85$** |
| **Recall@5** | $\ge 0.80$ | **$\ge 0.92$** |

## 5. Методика автоматизированного тестирования (КТ2)

На этапе КТ2 бенчмаркинг будет оформлен в виде автоматизированного тестового раннера (`python -m benchmark.run`), который:
1. Загружает корпус медицинских инструкций и строит индекс BM25.
2. Последовательно прогоняет тестовые запросы из `golden_dataset.json`.
3. Сравнивает выданные идентификаторы документов с эталонными `relevant_docs`.
4. Рассчитывает средние показатели $MRR$, $Recall@1$, $Recall@3$, $Recall@5$.
5. Выводит сводную таблицу в консоль и сохраняет артефакт отчета в формате Markdown для защиты.
