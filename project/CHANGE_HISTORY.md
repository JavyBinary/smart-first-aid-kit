# CHANGE_HISTORY.md — Журнал изменений проекта MedAI

Все существенные изменения в спецификациях, архитектуре и интерфейсах фиксируются в данном документе.

---

## [v0.1.0-kt1] — 2026-10-05
### Контрольная Точка 1: Формирование концепции, SDD-спецификаций и UI-прототипа

- **Инициаторы:** Тимлид (Лука Чоботов), Полина (бэкенд), Катя (фронтенд)
- **Цель этапа:** Сдача Контрольной Точки 1 согласно требованиям НИРС (МГТУ им. Н. Э. Баумана).

#### Добавлено:
1. **Базовая структура репозитория по методологии SDD:**
   - `README.md` — паспорт проекта, состав команды, статус КТ1, инструкция запуска прототипа.
   - `AGENTS.md` — регламент взаимодействия AI-агентов с кодовой базой и спецификациями.
   - `CHANGE_HISTORY.md` — данный журнал изменений.
2. **Продуктовая спецификация (`spec/product/`):**
   - `product.md` — описание идеи, цели, стейкхолдеры, границы проекта, медицинский дисклеймер, применение правила 20/80.
   - `roles.md` — детальное описание двух обязательных ролей пользователей: Обычный пользователь (`User`) и Администратор базы знаний (`Admin`), матрица прав доступа (RBAC).
   - `scenarios.md` — пошаговый сквозной сценарий подбора лекарства из наличия («Головная боль»), альтернативные сценарии инвентаризации, проверки совместимости и экстренный протокол первой помощи.
   - `ui_spec.md` — описание экранов, дизайн-системы, состояний элементов интерфейса и пользовательских потоков.
3. **Техническая спецификация (`spec/tech/`):**
   - `architecture.md` — компонентная архитектура приложения, схема потоков данных (Data Flow), изоляция модулей.
   - `rag.md` — математический аппарат поискового движка BM25 (по `НИРС.pdf`), пайплайн токенизации и лемматизации, концепция Context Injection для LLM.
   - `benchmark.md` — методология валидации поиска, формулы Recall@k и MRR, спецификация эталонного датасета запросов.
   - `api.md` — проект контрактов REST API (авторизация, управление инвентарем аптечки, поиск и диалог, администрирование).
4. **Статические интерактивные прототипы UI (`ui/`):**
   - `ui/auth.html` — экран входа и регистрации с сохранением сессии в `localStorage`.
   - `ui/app.html` — экран личного кабинета: инвентарь аптечки, фильтрация по категориям, модальные окна и окно диалога с MedAI.
   - `ui/admin.html` — прототип панели администратора для управления корпусом медицинских инструкций и просмотра метрик качества поиска.

#### Обоснование проектных решений:
- В соответствии с указанием преподавателя («заметки_препода.txt»), реализовано разграничение на 2 типа пользователей (Пользователь и Администратор).
- Для строгого соответствия требованиям КТ1 полностью исключен серверный код — весь фокус направлен на прозрачность документации и наглядность пользовательского интерфейса.
