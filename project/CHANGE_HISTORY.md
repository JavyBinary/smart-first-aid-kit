## [0.1.0-kt1] — 2026-10-05
### Контрольная Точка 1: Архитектурные спецификации SDD и прототип интерфейса

#### Добавлено:
- **Базовая структура репозитория:**
  - `README.md` — паспорт проекта, состав команды, статус КТ1 и карта SDD.
  - `AGENTS.md` — единый регламент для AI-ассистентов всех участников команды.
  - `GEMINI.md` — системный промпт со строгими инвариантами разработки.
  - `.gitignore` — исключение системных файлов ОС и временных кэшей.
- **Продуктовые спецификации (`spec/product/`):**
  - `product.md` — концепция сервиса, целевые пользователи, границы системы, стратегия 20/80.
  - `roles.md` — спецификация двух ролей (User и Admin), матрица прав RBAC.
  - `scenarios.md` — основной сценарий (UC-01), инвентаризация (UC-02), совместимость (UC-03), экстренный протокол (UC-04).
  - `ui_spec.md` — спецификация интерфейса, описывающая утвержденный макет Кати (`auth.html`, `site.html`).
- **Технические спецификации (`spec/tech/`):**
  - `architecture.md` — компонентная архитектура, Data Flow, разделение модулей команды.
  - `rag.md` — математический аппарат BM25, токенизация, лемматизация, Context Injection.
  - `benchmark.md` — метрики качества (Recall@k, MRR), формат тестового набора запросов.
  - `api.md` — контракты REST API для авторизации, аптечки, RAG-диалога и панели админа.
- **Утвержденные файлы интерфейса (`ui/`):**
  - `ui/auth.html` — экран входа и регистрации, разработанный Катей.
  - `ui/site.html` — основной экран аптечки и чата, разработанный Катей.

#### Исправлено:
- Восстановлены оригинальные файлы Кати (`auth.html`, `site.html`) без изменений и без выдуманных макетов.
- Исключены любые декоративные эмодзи из технической документации.
- Все ссылки в Markdown стандартизированы как строго относительные.
- Регламенты `GEMINI.md` и `AGENTS.md` приведены к единому стандарту для всей команды (Лука, Полина, Катя).
