# MedAI — Умная домашняя аптечка

Интеллектуальный веб-сервис персональной инвентаризации домашней аптечки и безопасного подбора средств доврачебной помощи на базе **BM25** и **LLM**.

Проект разрабатывается в рамках научно-исследовательской работы студентов (НИРС 2026, МГТУ им. Н. Э. Баумана).  
Дисциплина: *Разработка RAG-приложения с помощью LLM*.  
Преподаватель: *Кирибаев Т. Е.*

---

## 1. Запуск прототипа интерфейса

```bash
# Запуск локального веб-сервера
python3 -m http.server 8000
```
- Экран входа и регистрации: [ui/auth.html](ui/auth.html) (`http://localhost:8000/ui/auth.html`)
- Основной кабинет пользователя: [ui/site.html](ui/site.html) (`http://localhost:8000/ui/site.html`)
- Панель администратора базы знаний: [ui/admin.html](ui/admin.html) (`http://localhost:8000/ui/admin.html`)

---

## 2. Основной сценарий (Primary Use Case)

Пользователь вводит симптомы недомогания $\rightarrow$ поисковый модуль BM25 находит релевантные официальные инструкции Минздрава РФ $\rightarrow$ система сопоставляет активные вещества с аптечкой пользователя $\rightarrow$ LLM формирует структурированный ответ с точной дозировкой, противопоказаниями и предупреждениями. Подробное описание в [spec/product/scenarios.md](spec/product/scenarios.md).

---

## 3. Команда и роли

- **Лука (Тимлид):** Архитектура SDD, разработка базовых спецификаций, ядро BM25, токенизация и лемматизация, бенчмаркинг ($MRR$, $Recall@k$).
- **Полина:** Backend & API, ревью и валидация спецификации REST API, реализация серверного слоя на FastAPI, интеграция с LLM.
- **Катя:** Frontend & UI/UX, реализация клиентского интерфейса (`ui/auth.html`, `ui/site.html`, `ui/admin.html`), дизайн-система и валидация сценариев.
