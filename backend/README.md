# MedAI Backend Service

Серверный сервис интеллектуальной аптечки первой помощи MedAI (НИРС ИУ5 МГТУ им. Н. Э. Баумана).

## Архитектура
- **Фреймворк:** FastAPI (Python 3.12).
- **СУБД:** PostgreSQL 17 (SQLAlchemy 2.0 async + asyncpg).
- **Кэш и сессии:** Redis 7 (ротация сессий, rate limiting, отзыв токенов).
- **Поисковое ядро RAG:** BM25 Core с лемматизацией `pymorphy3`.
- **Конфигурация:** Pydantic v2 Immutable models.
- **Логирование:** Структурированное логирование с контекстными переменными (x-request-id) и защитой от утечек PII.

## Запуск в локальном окружении
```bash
# Синхронизация зависимостей
uv sync

# Запуск тестов
uv run pytest

# Проверка качества кода
uv run ruff check .
```
