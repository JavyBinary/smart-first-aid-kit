# Руководство: Фаза Implement (Реализация)

На этапе `implement` выполняется кодирование в соответствии с утвержденным `plan.md`.

## Правила этапа:
1. Разработка ведётся небольшими проверяемыми инкрементами.
2. Не допускается отклонение от требований `spec.md`. При необходимости изменения логики сначала обновляется `spec.md`.
3. Для серверного кода и ядра поиска: сначала реализуются unit-тесты (TDD), затем целевой код.
4. Прогон линтера и тестов выполняется через единый `Makefile`:
   ```bash
   make lint
   make test
   ```
5. Код оформляется в строгом стиле, без временных отладочных принтов и мусорных файлов.
