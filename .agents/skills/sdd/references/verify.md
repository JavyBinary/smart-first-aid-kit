# Руководство: Фаза Verify (Верификация и доказательство)

На этапе `verify` фиксируются объективные доказательства того, что реализация полностью соответствует требованиям спецификации.

## Правила этапа:
1. Создать файл `specs/changes/<change-id>/verification.md`.
2. Файл обязан содержать:
   - Дату верификации и итоговый вердикт.
   - **Таблицу соответствия требований (Traceability Matrix):**
     | Идентификатор требования | Способ проверки / Тест | Результат |
     |---|---|---|
     | REQ-001 | Тест `test_bm25_idf` в `tests/test_bm25.py` | Пройдено |
   - Терминальный вывод выполненных команд проверки (`make test`, `make bench`, `git diff --stat`).
3. Только после успешного формирования `verification.md` статус в `specs/status.yaml` переводится в `done`:
   ```bash
   python3 .agents/skills/sdd/scripts/spec_status.py update <change-id> done
   ```
4. Фиксация изменений отражается в [CHANGE_HISTORY.md](../../../../CHANGE_HISTORY.md).
