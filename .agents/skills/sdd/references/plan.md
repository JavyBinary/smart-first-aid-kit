# Руководство: Фаза Plan (Инженерное планирование)

На этапе `plan` формируется пошаговый технический план реализации согласованной спецификации.

## Правила этапа:
1. Создать файл `specs/changes/<change-id>/plan.md`.
2. Обновить статус в реестре на `in-progress`:
   ```bash
   python3 .agents/skills/sdd/scripts/spec_status.py update <change-id> in-progress
   ```
3. План должен содержать:
   - **Основание:** ссылку на `spec.md` и перечень реализуемых `REQ-xxx`.
   - **Архитектурные решения:** выбор структур данных, алгоритмов, схемы интеграции.
   - **Порядок реализации:** последовательные атомарные шаги с указанием точных путей к файлам.
   - **Стратегия тестирования:** какие unit/integration тесты будут написаны для подтверждения каждого `REQ-xxx`.
4. Запрещено приступать к фазе `implement` без утверждения плана тимлидом.
