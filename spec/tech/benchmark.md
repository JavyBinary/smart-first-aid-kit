# Методология оценки качества поиска (Benchmark)

Спецификация разработана в соответствии с требованиями раздела 1.5 и раздела 2 («Задание») методических указаний НИРС (`НИРС.pdf`).

---

## 1. Методология тестирования

1. Формируется контрольный набор из 45 запросов $Q = \{q_i\}_{i \in I}$, равномерно покрывающий категории корпуса (НПВП, спазмолитики, антибиотики, ЖКТ, антисептики, антигистаминные).
2. Для каждого запроса $q_i$ экспертно зафиксировано **не менее 3 релевантных документов** ($|R_{q_i}| \ge 3$).
3. Запросы сформулированы естественным языком бытовых симптомов без прямого копирования цитат из инструкций.

---

## 2. Расчетные формулы метрик

### 2.1. Mean Reciprocal Rank (MRR)
Оценивает позицию первого найденного релевантного документа в выдаче:
$$MRR = \frac{1}{|Q|} \sum_{i \in I} \frac{1}{\text{rank}_i}$$
где $\text{rank}_i$ — позиция первого документа из множества $R_{q_i}$ в ранжированном списке (если не найден, $\frac{1}{\text{rank}_i} = 0$).

### 2.2. Recall@k (Полнота поиска на глубине k)
Доля релевантных документов, попавших в топ-$k$ позиций:
$$\text{Recall@k} = \frac{1}{|Q|} \sum_{i \in I} \frac{|Top_k(q_i) \cap R_{q_i}|}{|R_{q_i}|}$$

- **Recall@1:** попадание первого релевантного документа на позицию 1.
- **Recall@3:** ключевой показатель для RAG (в контекст передается 3 документа).
- **Recall@5:** расширенная полнота выдачи.

---

## 3. Критерии приемки для защиты КТ2

| Метрика | Минимальный порог | Целевой уровень |
|---|:---:|:---:|
| **MRR** | $\ge 0.65$ | **$\ge 0.80$** |
| **Recall@3** | $\ge 0.70$ | **$\ge 0.85$** |
| **Recall@5** | $\ge 0.80$ | **$\ge 0.92$** |

## 5. Процедура автоматического запуска (КТ2)

Для запуска бенчмарка в КТ2 будет использоваться команда:
```bash
python -m benchmark.run --dataset benchmark/golden_dataset.json --top_k 3
```
Результаты автоматически формируются в виде таблицы с метриками и сохраняются в отчетный Markdown-файл для защиты.
